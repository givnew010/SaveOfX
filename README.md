# X Folders

تطبيق ويب متطور لحفظ وتنظيم منشورات وتغريدات منصة **X** في مجلدات ومجموعات مخصصة، تم إعادة بناؤه بتقنيات **React + TypeScript + Tailwind CSS + Express**.

## المزايا الرئيسية

- **حفظ التغريدات بالرابط أو عبر رابط المشاركة**: استيراد روابط منشورات X (`x.com`, `twitter.com`, `fxtwitter.com`, `vxtwitter.com`) مع تنظيف تلقائي للرابط وجلب النص، بيانات الكاتب، الصورة الشخصية، الوسائط (صور، فيديو، GIF)، التغريدات المقتبسة، والإحصائيات عبر خادم `/api/tweet`.
- **تنظيم المجلدات**: إنشاء، تعديل، وحذف المجلدات مع اختيار أيقونة إيموجي ولون تمييز مخصص ووصف، وإمكانية نقل العلامات إلى المجلد الافتراضي عند حذف أي مجلد.
- **تصفية وبحث فوري**: تصفية حسب كل العلامات، المفضلة، أو أي مجلد، مع شريط بحث فوري في المحتوى، اسم الكاتب، المعرف، الملاحظات الشخصية، والوسوم.
- **ملاحظات ووسوم شخصية**: إضافة ملاحظة خاصة ووسوم تصنيف لكل منشور محفوظ.
- **عرض الوسائط**: شبكة صور متجاوبة مع عارض ملء الشاشة (Lightbox) ومشغل فيديو/GIF مدمج.
- **وضع ليلي ونهاري + دعم RTL كامل**: واجهة عربية متجاوبة تدعم الوضعين النهاري والليلي مع حفظ البيانات محلياً في المتصفح (`localStorage`).

## التشغيل والتطوير

```bash
npm install
npm run dev
```

يعمل الخادم على المنفذ `3000`. لبناء النسخة الإنتاجية وتشغيلها:

```bash
npm run build
npm start
```
