# X Folders (مجموعات X) — Android Native

تطبيق أندرويد أصلي مكتوب بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** لحفظ وتنظيم منشورات وتغريدات منصة **X** في مجموعات مخصصة.

## المزايا الرئيسية

- **تطبيق أندرويد أصلي (Kotlin + Android SDK)**: واجهة عربية كاملة تدعم RTL والوضعين النهاري والليلي مع حفظ البيانات محلياً عبر **Room Database**.
- **الاستقبال عبر المشاركة المباشرة (`ACTION_SEND`)**: مشاركة أي رابط تغريدة مباشرة من تطبيق X إلى التطبيق مع تنظيف الرابط وجلب النص، الكاتب، الصورة الشخصية، الوسائط (صور، فيديو، GIF)، التغريدات المقتبسة، والإحصائيات عبر OkHttp و Moshi.
- **توسيع النصوص الطويلة (`عرض المزيد` / `عرض أقل`)**: اختصار النصوص الطويلة تلقائياً عند 6 أسطر مع زر عرض المزيد بأسلوب منصة X.
- **إدارة المجموعات**: إنشاء، تعديل، وحذف المجموعات مع اختيار الأيقونة ولون التمييز والوصف.
- **الإعدادات والنسخ الاحتياطي**: تصدير نسخة احتياطية بصيغة JSON عبر Storage Access Framework أو الحافظة، واستعادتها بوضع الدمج أو الاستبدال، بالإضافة إلى تبديل مظهر التطبيق.

## البناء والتشغيل

```bash
gradle testDebugUnitTest
gradle assembleDebug
```

يتم توليد ملف الـ APK في:
`app/build/outputs/apk/debug/app-debug.apk`
